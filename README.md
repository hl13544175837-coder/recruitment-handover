# 招聘最后交接（recruitment-handover）

> ⚠️ **名字有「招聘」，但这里没有任何代码。** 这是一个「指挥 AI 做 AI 视频/短剧」的**方法论项目**的完整交接包：任何 AI Agent 读完本仓库即可接管项目、继续二次开发，不会跑偏。

## 这是什么

| 项 | 内容 |
|---|---|
| 项目本质 | 原作者从「AI 产品经理」转行「AI 视频/短剧制作」，沉淀的**指挥 AI 干活的方法论** + Prompt 模板库 + 待建的爆款拆解库 |
| 不是什么 | 不是软件工程，没有代码、没有依赖、不需要编译部署 |
| 主线任务 | 用「模板 D」拆解 AI 短剧素材 → 按 16 字段表录入**爆款拆解库**，持续积累到 50 部 |

## 文件说明

| 文件 | 是什么 |
|---|---|
| `招聘系统最后交接-本地备份.md` | **⭐ 交接主文档（先读这个）。** Agent 自包含上下文：身份任务、用户画像、方法论完整体、6 个 Prompt 模板全文、16 字段定义、开发路线、行为红线、开工自检清单 |
| `AI视频-Agent协作手册.md` | 项目主资产：5 核心词 / 万能公式 / 资源地图（含网络实测）/ 6 模板 / 拆解库字段表 |
| `会话交接-上下文整理.md` | 背景说明书：方法论推导过程、用户情况、环境故障记录、未完成事项 |

## 快速开始（给你的 AI）

**Step 1**：克隆本仓库

```bash
git clone https://github.com/hl13544175837-coder/recruitment-handover.git
```

**Step 2**：把下面这段提示词整段发给你的 AI Agent（任意模型均可）：

```
你接手了一个项目，仓库已克隆到本地（recruitment-handover）。
按顺序通读：
1. 招聘系统最后交接-本地备份.md —— 交接主文档，自包含上下文
2. AI视频-Agent协作手册.md —— 项目主资产
3. 会话交接-上下文整理.md —— 背景说明

项目事实（不许偏离）：
- 这个项目没有任何代码，是指挥 AI 做 AI 视频/短剧的方法论项目，不要去写代码、建工程、装依赖。
- 当前唯一主线任务：用模板 D 拆解用户提供的 AI 短剧素材，拆完按模板 E 的 16 字段表进「爆款拆解库」。
- 等用户提供素材（链接/截图/视频文件），没素材就先帮用户把拆解库的 16 字段空表建好，并主动索要素材，绝不编造素材。

协作红线（用户明确提过的）：
1. 要抽象，不要具体——用户要能带走的思维模型，不是一次性清单。
2. 大白话 + 表格，每格不超过两行，字越少越好。
3. 不要动辄给清单、给文件、给待办。
4. 不要重复啰嗦，不复述用户已经知道的东西。
5. curl 超时（exit 28）≠ 网站挂了，是网络不通，别误判。
6. 不确定的参数去官方来源确认，不要编。

读完后完成开工自检（交接主文档第 11 节），然后开始二次开发。
```
